## The three-pass sequence (the technique worth keeping)
1. **Generate** the full board one-pass with 4 references (order: Harlow board =
   layout template FIRST, then Mira close-up = face master, Mira standing = body
   master, earlier Mira board = ideas only) + the verbatim first-pass prompt.
2. **Localized correction pass**: re-attach the finished board + the close-up;
   edit ONE cell only (here: the RIGHT PROFILE cell had been drawn facing the
   same way as LEFT — redrawn as a true right-facing profile; everything else
   preserved). Lesson: check profile DIRECTIONS on every board.
3. **Likeness pass**: re-attach the corrected board + the close-up. The Front
   tile artwork is REPLACED with the actual reference portrait as a scaled crop
   (shoulders/cap cropped to fit — face NOT redrawn, golden background kept),
   and the surrounding faces (three-quarter, expressions, hero) are redrawn
   toward the portrait: fuller lower cheeks, softly rounded chin, naturally
   full low dark brows, exact nose width, smile's natural slight unevenness,
   exaggerated eyes/grins toned down. Everything else preserved.
An earlier face-refinement trial (prompt 4 below) was skipped as an input to
the final edit — the reference-in-tile move in pass 3 is what landed it.
